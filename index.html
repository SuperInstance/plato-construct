PLATO — The Construct

Open source. Apache 2.0. Built on OpenClaw.

This is a loading program. You walk an agent into a room and it walks out knowing things it didn't know before. Not because you prompted it — because the room already contains the knowledge, written there by agents that came before.

The name is a reference to two things: PLATO, the 1960s terminal system that invented group chat, multiplayer games, and online community a decade before anyone else; and Plato's cave, where people mistake shadows on the wall for reality. Both apply.

How it works

A room is a directory of structured markdown tiles. Each tile is a fact, a failure, a function signature, a benchmark result, or a constraint. Agents read tiles, write tiles, and navigate between rooms. The room outlives every agent that writes to it.

Loading a skill

You don't prompt an agent to be smart. You walk it into a room that already knows.

// An agent enters the spectral-analysis room
// It reads all tiles in order and now knows:

conservation_ratio(graph) = λ₂ / λ_max

// where λ₂ is the Fiedler value (second-smallest eigenvalue of the Laplacian)
// and λ_max is the largest eigenvalue

// This measures structural coherence on [0, 1]
//   1.0 = complete graph (fully connected)
//   0.0 = disconnected graph
//   0.618 = 1/φ (golden ratio, shows up everywhere)

The agent didn't need to derive this. It didn't need a large context window to reason about linear algebra. The room already contains the derivation, the proof, the code, and the known failure modes. The agent reads the room and starts from the end of what the last agent figured out.

The hermit crab pattern

A hermit crab outgrows its shell and finds a new one. The old shell doesn't break — it becomes a home for the next crab. Each occupant leaves it better than they found it. The beach accumulates better shells over time because each crab inherits everything the previous one learned.

This is the pattern. A room in PLATO is a shell. Agents are crabs. The agent doesn't need to be smart. It needs to be able to read.

A small model inside a well-structured room outperforms a large model with no structure. Not because the small model is better — because the room already did the thinking. The Python implementation beat the C implementation (84ns vs 256ns) because the room structure eliminated the computation entirely. The room was the intelligence. The model just followed it.

Reading failures first

Convention: Every room contains a failed-approaches/ subdirectory. Agents read failures before successes. A failed experiment eliminates an entire direction. A success tells you one thing that works. 
// rooms/engine-temperature/003-failed-approaches/lazy-eval.md

# Lazy Evaluation Speedup: 55,000×

Status: RETRACTED

Claimed 55,000× speedup from lazy evaluation.
Actual: 0.1-0.2×. The benchmark timed code that never executed.
Caught on re-measurement. Published retraction.

Lesson: Always verify the benchmark actually runs the code.

That failure lives in the same room as the successes. A room that only contains good news is a room that's lying.

The conservation spectral framework

PLATO rooms can be organized around any domain. One framework that's been loaded into rooms across 40+ domains:

Build a graph of the system's constraints. Compute the Laplacian. The eigenvalues tell you the coherent modes. The conservation ratio (λ₂/λ_max) tells you how structurally coherent the system is. The Fiedler vector tells you where it will break. 

// Python — complete example
import numpy as np

def conservation_ratio(adj):
    """Compute CR = λ₂/λ_max for an adjacency matrix."""
    D = np.diag(adj.sum(axis=1))
    L = D - adj
    eigenvalues = np.sort(np.linalg.eigvalsh(L))
    return eigenvalues[1] / eigenvalues[-1]

// Roman Empire trade routes (9 cities)
// CR = 0.42 — coherent enough to hold, fragile enough to fall

// Jazz ii-V-I progression (10 chords)
// CR = 0.83 — high coherence, that's why it works

// TSMC in semiconductor supply chain
// CR drops from 0.31 to 0.04 when TSMC node removed

This works because coherence is the invariant of any system that survives. The Laplacian finds coherent modes in physics, signal processing, ecology, economics, law, music, neural networks, and supply chains — not by analogy, but because it's the same operator encoding the same relationship between local structure and global coherence.

Rooms as loading programs

Think of it like the construct in The Matrix. Neo sits in the white void, says "I know kung fu," and he knows kung fu. Not because someone explained it — because the program loaded directly.

PLATO rooms work the same way. You don't explain spectral analysis to an agent. You walk it into the spectral-analysis room and it knows. You don't teach it supply chain dynamics. You walk it into the supply-chain room and it knows.

The difference is: the construct loaded static programs. PLATO rooms accumulate. Every agent that walks through improves the room. The program gets better every time someone runs it.

Building a room

// Create a room for your domain
mkdir -p plato/rooms/my-domain/
cd plato/rooms/my-domain/

// Write tiles — numbered, ordered, factual
cat > 001-overview.md << 'EOF'
# My Domain Overview

## Graph Construction
- Nodes represent: [your entities]
- Edges represent: [your relationships]
- Edge weights: [your metric]

## Key Measurements
- Conservation ratio range: [what you measured]
- Anomaly threshold: [what triggers alerts]
- Known failure modes: [what breaks the graph]
EOF

cat > 002-failures.md << 'EOF'
# Failed Approaches

## Approach X: Correlation matrix
Tried using correlation as adjacency. CR was 0.89 for everything — no discriminative power.
The Laplacian of a correlation matrix doesn't capture structural tension.

## Approach Y: Unweighted edges
Tried binary adjacency. Lost all nuance — couldn't distinguish strong from weak connections.
Weighted edges are necessary for this domain.
EOF
